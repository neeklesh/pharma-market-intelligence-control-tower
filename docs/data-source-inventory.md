# Data Source Inventory

## Purpose
Maintain an inventory of public data sources used in this project.

| Source | Data Category | Geography | Access Method | Status |
|---|---|---|---|---|
| ClinicalTrials.gov | Clinical trials | Global | API | Planned |
| World Bank | Economic indicators | Global | API | Planned |
| WHO | Health indicators | Global | API | Planned |
| OpenFDA | Regulatory and drug data | USA/global relevance | API | Planned |
| CDSCO | Regulatory information | India | Website | Planned |
| HSA | Regulatory information | Singapore | Website | Planned |
| NPRA | Regulatory information | Malaysia | Website | Planned |
| Thai FDA | Regulatory information | Thailand | Website | Planned |
| PMDA | Regulatory information | Japan | Website | Planned |
| Company Investor Relations | Company information | Global/APAC | Website/reports | Planned |

## Source Documentation Requirements
For each source, record:
- Source name
- URL
- Data description
- Geographic coverage
- Update frequency
- Access method
- Extraction date
- Data limitations
- Licence or usage restrictions

## Data Policy
Only use sources whose access and usage conditions are understood and acceptable for this project.
