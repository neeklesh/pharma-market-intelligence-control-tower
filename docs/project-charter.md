# Project Charter

## Project Name
Pharma Market Intelligence & Commercial Strategy Control Tower

## Project Objective
Build a data-driven pharmaceutical market intelligence and commercial analytics platform focused on selected Asia-Pacific markets.

## Geographic Scope
- India
- Singapore
- Malaysia
- Thailand
- China
- Japan

## Therapeutic Focus
- Type 2 Diabetes
- Obesity
- GLP-1 therapies

## Project Goals
- Analyse market opportunities.
- Track competitors.
- Monitor clinical pipelines.
- Track regulatory developments.
- Analyse pricing and market access.
- Build commercial analytics models.
- Develop forecasting models.
- Build an AI-assisted market intelligence tool.

## Technology Stack
- Python
- SQL
- PostgreSQL
- Power BI
- Streamlit
- GitHub

## Data Policy
Use publicly available data and synthetic data wherever commercial data is unavailable.

Document all assumptions, limitations and methodologies.
