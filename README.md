# Pharma Market Intelligence & Commercial Strategy Control Tower

## Overview

An independent analytics project designed to analyse pharmaceutical market dynamics, competitive intelligence, clinical pipelines, regulatory developments and commercial opportunities across selected Asia-Pacific markets.

## Geographic Scope

- India
- Singapore
- Malaysia
- Thailand
- China
- Japan

## Therapeutic Focus

- Type 2 Diabetes
- Obesity
- GLP-1 therapies
- Relevant competitive and therapeutic developments

## Project Objectives

- Analyse pharmaceutical market opportunities.
- Monitor competitor activities.
- Track clinical pipeline developments.
- Monitor regulatory events.
- Analyse public pricing and affordability indicators.
- Develop commercial analytics models.
- Build scenario-based forecasts.
- Develop AI-assisted market intelligence capabilities.

## Technology Stack

- Python

- Statistics

## Project Modules

1. Market Intelligence
2. Competitive Intelligence

6. Commercial Analytics
7. Forecasting & Scenario Planning
8. AI Market Intelligence Assistant

## Data Policy

This project uses public data sources and synthetic datasets where real commercial data is unavailable.

All estimates, assumptions, simulations and analytical limitations will be documented.
